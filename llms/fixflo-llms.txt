# Fixflo

> Fixflo (a trading name of Tactile Limited, London, UK; acquired by Aareon in 2021) is a UK repairs, maintenance and compliance management platform for lettings agents, block managers and commercial property managers. Occupiers report issues through a guided fault tree; Fixflo routes the work to contractors and tracks jobs, service programmes, warranties and invoices, syncing records back to the agency CRM. Its OpenAPI is genuinely public and downloadable without logging in — but calling the API requires a signed licence agreement, a token generated inside a customer's own Fixflo account, and that customer's own subdomain as the base host.

Generated by API Evangelist (apievangelist.com) from the public Fixflo developer portal and the artifacts in https://github.com/api-evangelist/fixflo. Not a Fixflo publication.

## Read this first

- Fixflo publishes no llms.txt of its own. This file is generated.
- The contract is open; the runtime is not. Read the OpenAPI freely; sign the Application Developer and API Licence Agreement to call it.
- There is no self-serve signup, no developer dashboard and no self-issued key. Start at support@fixflo.com.
- The base URL is not a constant: production is https://[your subdomain].fixflo.com/api/v2, one host per agency account.

## Access

- [Application Developer and API Licence Agreement (PDF)](https://fixflostore.blob.core.windows.net/live-assets/SystemApplicationDeveloperAndAPILicenseAgreement.pdf): must be signed before any use of the API.
- Contact: support@fixflo.com — describe the use case, register the app, request a sandbox.
- Auth: `Authorization: Bearer [token]`, a 64-character alphanumeric token generated by a user inside their Fixflo system. No scopes.
- Rate limit: "not below 500 requests a minute"; HTTP 429 on breach. No Retry-After documented.
